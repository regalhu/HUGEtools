# 2026-07-09 · v0.7.10 分享二维码与小程序转发

## 官方能力判断

- 微信小程序前端允许使用 `button open-type="share"` 触发 `Page.onShareAppMessage`，用于用户主动转发给微信好友。
- 微信小程序码属于微信服务端开放接口，典型路径为 `/wxa/getwxacodeunlimit`。该能力需要服务端 access token，不能把 AppSecret 写进 Web 前端或小程序包。
- 因此本次实现分为两层：小程序内优先使用原生转发；小程序码由云服务器可选生成。

## 本次变化

- Web 端新增“分享二维码”工具入口。
- Web 端可生成当前公网链接二维码、复制链接、调用浏览器系统分享面板。
- Node 服务新增 `/api/share-qr.svg`，使用 `qrcode` 生成普通网页链接 SVG 二维码。
- Node 服务新增 `/api/miniprogram-code`，服务器配置 `WECHAT_APPID` 和 `WECHAT_APPSECRET` 后可调用微信服务端接口生成小程序码。
- 小程序端新增“分享”工具入口，支持原生转发、复制小程序路径、复制公网链接和请求云端生成小程序码。
- 小程序版本更新为 `0.7.10-miniapp.1`，已同步工具数更新为 14。

## 风险边界

- Web 端二维码是网页链接二维码，不等于微信小程序码。
- 小程序码生成依赖云服务器环境变量、微信后台合法域名和生产 HTTPS 配置。
- 未配置微信密钥时，`/api/miniprogram-code` 会明确返回 `wechat_not_configured`，小程序端仍可使用原生转发。

## 验证

- `server.js`、`app.js`、`slider-fix.js`、`version-archive.js`、`miniprogram/app.js`、`miniprogram/pages/index/index.js` 和 `miniprogram/utils/calc.js` 需要通过 `node --check`。
- `data/version-history.json`、`miniprogram/version.json`、`project.config.json`、`miniprogram/app.json` 和 `package.json` 需要通过 JSON 校验。
- 本地 Node 服务需要验证 `/api/share-qr.svg` 返回 SVG，`/api/miniprogram-code` 在未配置微信密钥时返回 501。
- 微信开发者工具 CLI 需要生成新的小程序预览二维码。
