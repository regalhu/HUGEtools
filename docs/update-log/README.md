# 本地更新文档索引

这个目录用于保存胡哥餐饮工具箱每次更新的本地 Markdown 记录，方便 ChatGPT 或后续维护者快速对齐版本背景。

## 记录规则

- 每次功能、部署、版本或重要配置更新，都新增或补齐一份 `YYYY-MM-DD-vX.Y.Z.md`。
- 内容需要和 `data/version-history.json`、`version-archive.js` 的版本标题和验证结论保持一致。
- 如果更新包含部署，必须明确写出部署入口、服务器路径、验证结果和未完成风险。
- 如果部署没有完成，也要如实记录“未完成”和阻塞原因。
