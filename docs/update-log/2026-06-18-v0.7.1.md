## 风险与待办

- 仓库改为私有后，服务器若继续使用 Git 拉取部署，必须确保服务器具备可访问私有仓库的 deploy key 或 token。
- 恢复 SSH 后，需要在服务器上检查 `/www/hugetools`、`hugetools.service`、`hugetools-webhook.service`、Nginx 配置和安全组。
- 如果 80/443 未备案或未放行，需要继续保留明确的临时高位端口策略，避免误判为应用错误。
