# 2026-07-27 · v0.8.0 营运工作台与经营简报合并升级

## 本次目标

以辛香汇工作助手当前已核验版本为产品逻辑参考，在不修改其任何代码的前提下，更新胡哥餐饮工具 Web 与微信小程序。相同能力优先汇总复用，缺失能力按胡哥工具“本地优先、无账号、无云端经营数据上传”的边界适配。

## 功能合并

- 新增“营运工作台”统一入口，直接汇总和跳转现有门店任务提醒、员工激励，不重复建设任务、评分和排行榜。
- 原“门店营业额联合分析”升级为“经营分析与老板简报”，保留菜品销售结构覆盖率、门店标准化和完整月边界。

## 新增能力

- 今日总览。
- 会议纪要：日期 + 上午/下午、议题、负责人、计划完成日期、当前进度。
- 每日日志：今日完成、问题与风险、明日重点。
- 资料库：分类、内容、来源和适用范围。
- 培训反馈：主题、讲师、评分、复训状态和行动建议。
- 每日营运简报：Web 支持复制、TXT 下载、打印或保存 PDF；小程序支持复制。
- 经营简报指标：折后营业收入、到手收入、到手率、到手收入预算、全月预算达成率、时间进度预算达成率。
- 小程序工作台、任务和员工激励记录从页面内存升级为微信本机持久化。

## 数据口径

- 到手率 = 到手收入 ÷ 折后营业收入 × 100%。
- 任一到手收入缺失时，到手收入合计和到手率显示“不可计算”。
- 预算达成只读取显式录入的到手收入预算；预算缺失不按 0 处理。
- 菜品销售金额 / 折后营业收入仍只作为销售结构覆盖率参考，不等于毛利率或利润贡献。
- 每日营运简报只汇总当前浏览器或微信本机记录，未读取和未填写内容不自动推断。

## 与辛香汇工作助手的边界

- 未复制辛香汇工作助手的 Express、SQLite、认证、上传、业务数据库或部署代码。
- 胡哥工具不具备账号权限、云端多人协作、附件保护、正式经营数据入库和后台主动提醒。
- 辛香汇工作助手仓库在本次开发中保持只读，未产生任何代码改动。
