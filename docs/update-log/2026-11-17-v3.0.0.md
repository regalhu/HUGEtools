# 3.0 全工具首页与统一导航

基线：0.10.0。仅重构小程序导航与首页视觉，不改业务存储和计算口径。
- 新增独立首页，19 个工具及 5 个工作台快捷入口全部可达。
- 搜索、分类、卡片入口，采用 Apple 风格留白与层次；不使用 Apple 商标。
- 全部工具统一左上角返回首页；原内联工具仍保留既有功能，独立页面和分享深链接也可以无栈返回。
- 无 H5 web-view 页面；现有网页版独立存在，不冒充原生小程序页面。

验证、Logo来源及发布回执完成后补记。
