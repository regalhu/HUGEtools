# 2026-06-23 更新记录：v0.7.8

## 版本

- 当前版本：0.7.8
- 上一版本：0.7.7

## 变更范围

- 新增餐饮门店员工激励系统，定位为连锁门店执行力管理工具，不作为传统薪资系统。
- 新增任务管理模块，支持按店长、后厨、库管、前厅分配任务。
- 任务周期支持每天、每周和每月。
- 每个周期任务会自动生成执行记录。
- 新增评分引擎，按准时率、完成质量、是否遗漏计算评分。
- 新增积分系统，按基础积分和评分结果折算积分，用于奖金参考、排名、晋升候选和辅导提醒。
- 新增排行榜模块，展示员工积分、平均评分、准时率、遗漏数和激励标签。
- 前端新增今日任务页、我的评分页、门店排行榜页和任务管理页。

## 评分规则

- 准时表现占 40%。
- 完成质量占 45%。
- 是否遗漏占 15%。
- 任务遗漏或标记为遗漏时，质量和遗漏项会归零。
- 任务积分 = 基础积分 × 评分 / 100。

## 风险边界

该系统用于门店执行力管理和激励参考，不直接计算工资，不替代劳动合同、公司绩效制度、财务审批或人事晋升流程。
