# 2026-06-23 更新记录：v0.7.7

## 版本

- 当前版本：0.7.7
- 上一版本：0.7.6
- 日期：2026-06-23
- 主题：门店任务提醒工具

## 变更范围

- 新增门店任务提醒工具，支持新增、编辑、删除、启用和停用任务。
- 任务数据保存在浏览器本地 IndexedDB，localStorage 只保存角色筛选和视图筛选等轻量设置。
- 支持按角色筛选，按今日、逾期、已完成、启用中和全部任务查看。
- 支持一次性、每天、每周指定星期、每月指定日期、每月最后一天和自定义间隔提醒周期。
- 页面打开时自动检查错过提醒；页面运行期间每 60 秒检查一次到期任务并显示本地弹窗。
- 新增餐饮任务模板库：开店检查、闭店检查、收货检查、月度盘点、考勤提交、供应商对账、冰箱温度记录、外卖平台检查。
- 新增任务数据 Schema，方便后续小程序、导入导出或本地迁移复用字段结构。

## 风险边界

第一版只做稳定离线本地版，不做云同步、短信、微信推送或账号系统。页面关闭期间不会主动弹窗，错过的提醒会在下次打开页面时显示为逾期任务。
