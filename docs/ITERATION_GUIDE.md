# 胡哥餐饮工具箱迭代规则

本项目采用轻量“版本自引用”机制：每一次功能更新，都需要同步更新 `data/version-history.json`。

## 每次更新必须记录

- `version`：当前版本号。
- `date`：更新日期。
- `baseline`：对比的上一版本。
- `title`：本次迭代主题。
- `changes`：本次具体变化。
- `verification`：本次验证方式和结果。
- `riskBoundary`：风险边界和合规提醒。

## 迭代顺序

1. 先确认上一版本能力和问题。
2. 再做本次代码变更。
3. 完成后跑语法检查或页面验证。
4. 最后把本次变更追加到 `data/version-history.json`。

这样后续可以按版本回看：为什么改、改了什么、和上一版相比解决了什么问题。
